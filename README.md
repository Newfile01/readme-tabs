# Readme-tabs project
Light template for Readme tabs Jekyll-JavaScript based

```bash
mon-projet/
├── index.md          # Page principale avec les sections dépliables
├── _includes/
│   └── scripts.html  # Fichier pour le code JavaScript
└── _config.yml       # Configuration Jekyll
```
Activer GitHub Pages

Allez dans les paramètres de votre dépôt GitHub.
Dans la section Pages, choisissez la branche main (ou master) et le dossier racine (/).
Cliquez sur Save.
Votre site sera disponible à l’URL :
https://<votre-nom-d-utilisateur>.github.io/<nom-du-depot>/

6. Résultat

Navigation par ancres : Cliquez sur un lien dans le menu pour accéder directement à une section.
Dépliement automatique : La section ciblée par l’ancre s’ouvre automatiquement grâce au JavaScript.
Compatibilité : Fonctionne sur tous les navigateurs modernes.
